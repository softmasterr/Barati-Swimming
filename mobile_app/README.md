# اپلیکیشن اندروید آکادمی شنای براتی (Barati Swimming App)

این پروژه اپلیکیشن موبایل نیتیو مبتنی بر **Flutter (Dart)** است که به طور اختصاصی برای مدیریت استخر، ثبت حضور و غیاب با کارت‌های NFC و حسابداری آکادمی شنا طراحی شده است.

---

## 📱 امکانات کلیدی اپلیکیشن

1. **سنسور سخت‌افزاری NFC (سراسری / Foreground Dispatch):**
   - در هر صفحه‌ای از برنامه که باشید، به محض نزدیک شدن مچ‌بند یا کارت به پشت گوشی، سنسور فعال شده و دیالوگ تایید ورود و کسر جلسه نمایش داده می‌شود.
   - دارای شبیه‌ساز مچ‌بندهای تست درون برنامه برای آزمایش سریع بدون نیاز به کارت فیزیکی.
   - بازخورد فیزیکی دوگانه: ویبره سخت‌افزاری (Haptic) متناسب با وضعیت تردد + بوق صوتی تایید/هشدار/خطا.

2. **پایگاه‌داده محلی کاملاً آفلاین (SQLite با Sqflite):**
   - تمامی اطلاعات ورزشکاران، مربیان، دوره‌ها، تراکنش‌ها و صف همگام‌سازی در پایگاه‌داده داخلی گوشی ذخیره می‌شود.
   - حتی با قطع کامل اینترنت در زیرزمین یا محوطه استخر، برنامه با حداکثر سرعت کار می‌کند.
   - به محض اتصال مجدد به اینترنت، عملیات معلق با سرور ابری همگام می‌شوند.

3. **حسابداری جامع و امور مالی:**
   - ثبت شهریه‌ها، دریافتی‌ها (نقدی، پوز، کارت‌به‌کارت) و بدهی/بستانکاری شاگردان.
   - محاسبه خودکار کارکرد مربیان با ۳ مدل قرارداد (درصدی، جلسه‌ای، حقوق ثابت ماهانه) و ثبت تسویه‌حساب.
   - ثبت هزینه‌های جاری استخر (اجاره لاین، تجهیزات شنا و...).
   - لیست لحظه‌ای بدهکاران با قابلیت ارسال پیامک یادآوری.

4. **مدیریت وضعیت با الگوی رسمی Provider:**
   - کدنویسی تمیز، ساختار ماژولار و تفکیک لایه‌های داده، سرویس‌ها و رابط کاربری.

## 📂 ساختار فایل‌های پروژه

```
mobile_app/
├── android/                         # تنظیمات و مجوزهای نیتیو اندروید (NFC, Vibrate)
├── lib/
│   ├── models/                      # مدل‌های داده (ورزشکار، مربی، تراکنش، تردد، پیامک)
│   ├── services/
│   │   ├── database_helper.dart     # مدیریت پایگاه‌داده SQLite و Seed داده‌ها
│   │   ├── nfc_service.dart         # مدیریت سنسور سخت‌افزاری NFC
│   │   └── feedback_service.dart    # مدیریت ویبره و اصوات سیستم
│   ├── providers/
│   │   └── academy_provider.dart    # منطق اصلی کسب‌وکار و حسابداری
│   ├── screens/
│   │   ├── main_navigation_screen.dart # نوار ناوبری ۵ گانه و اسکنر سراسری
│   │   ├── scanner_screen.dart         # صفحه گیت تردد و شبیه‌ساز مچ‌بندها
│   │   ├── athletes_screen.dart        # مدیریت ورزشکاران و کارت‌ها
│   │   ├── coaches_screen.dart         # مربیان و تسویه‌حساب‌ها
│   │   ├── accounting_screen.dart      # داشبورد مالی، سود و زیان و هزینه‌ها
│   │   └── sms_screen.dart             # لاگ پیامک‌های ارسالی
│   ├── widgets/
│   │   ├── checkin_result_sheet.dart   # باتم‌شیت نتیجه ورود ورزشکار
│   │   └── sync_queue_dialog.dart      # پنجره صف همگام‌سازی آفلاین
│   └── main.dart                    # نقطه شروع برنامه با تم راست‌چین و فارسی
└── pubspec.yaml                     # وابستگی‌ها و پکیج‌های پروژه
```

## 🚀 روش‌های دریافت خروجی APK برای گوشی

### روش ۱: بیلد خودکار ابری با GitHub Actions (بدون نیاز به نصب فلاتر روی لپ‌تاپ)
در مسیر پروژه فایل `.github/workflows/build_apk.yml` تنظیم شده است. کافیست پروژه را در یک مخزن گیت‌هاب (GitHub) قرار دهید:
1. گیت‌هاب به صورت خودکار پروژه را کامپایل کرده و فایل `app-release.apk` را تولید می‌کند.
2. از تب **Actions** در صفحه گیت‌هاب، فایل APK را مستقیماً دانلود و روی گوشی خود نصب کنید.

### روش ۲: بیلد محلی (در صورتی که Flutter SDK روی سیستم نصب شود)
```bash
cd mobile_app
flutter pub get
flutter build apk --release
```
فایل نهایی در مسیر `mobile_app/build/app/outputs/flutter-apk/app-release.apk` قرار خواهد گرفت.
